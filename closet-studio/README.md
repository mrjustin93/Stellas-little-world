# Stella’s Closet — walkable 3D prototype

An unpublished mobile-first browser game with an original stylized 3D Stella, inspired by the supplied appearance reference: short blonde hair, blue eyes, white tank and shorts. The reference sheet is not a gameplay sprite sheet and is not loaded at runtime.

## Play locally
Open `Play-Stellas-Closet.html` in a compatible browser. The model and local code are embedded in that download. Three.js and its glTF loader require internet; failed 3D loading shows an explicit retry state, with no flat-character substitute. Optional Google Fonts also use the internet.

Some phone file viewers do not run JavaScript; they need the file opened in a browser or served locally. For development, use `python -m http.server 8000` in the project and open `http://localhost:8000`.

## Movement and controls
- Drag the circular thumbstick to walk; release to stop.
- Tap a clear point on the floor to walk there. Walls, shelves and furniture constrain movement. Tap walking is a direct route with collision stopping/sliding, not full obstacle-routing AI.
- Drag the background to rotate the camera. The camera follows Stella.
- Use WASD or arrow keys on a keyboard. Home button returns to the dressing rug.
- The Stella tab offers relaxed stance, confident stance, wave and face-camera actions. Walking cancels a gesture.
- Pause idle stops breathing, blinking and idle movement while leaving deliberate walking available. Reduced motion pauses idle by default.
- Room palettes, day/evening lighting, optional ambient sound, and PNG export remain available. Clothing is limited to the basic outfit for now.

## Character
`stella.glb` contains a genuine 16-bone deformation rig with weighted geometry. The continuous skin, sculpted pixie hair, face, eyes, tank and shorts are original Blender geometry. Runtime skeletal motion adds walking with alternating arms/legs, knee bending, grounded feet, breathing, head movement, blinking and a wave. This is an early stylized model, not an exact reconstruction of the reference or a final polished character.

Editable Blender source is generated by `art/build_stella.py`; see `art/README.md`. The mirror is decorative. Mobile layouts support portrait and landscape with a compact dressing tray and touch controls. Physical iOS/Android performance testing remains pending.

## Development
Source is in `dist/` locally, or at `closet-studio/` on the GitHub branch. `node --test tests/*.test.cjs` checks movement rules, collisions, packaging and the actual rigged asset. `python scripts/package.py` rebuilds the standalone file and ZIP. Browser tests are in `qa/mobile_check.py` and require Playwright/Chrome plus local server permissions.

This version replaces the earlier sprite-view experiment. Older screenshots/results in `qa/` describe earlier versions; `character-results.json` is the current walkable-character report. No deployment or merge has been performed.
